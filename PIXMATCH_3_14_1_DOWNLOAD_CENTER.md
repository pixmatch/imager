# PixMatch 3.14.1 — Multi-format Download Center

The top-right Download control is now a dropdown rather than a single HTML export.

Available exports:
- CSV results
- Excel-compatible `.xls` workbook with Measurements, Scientific, and Notes sheets
- Scientific graph PNG
- PDF report
- HTML report
- PIV vectors CSV when PIV results exist

The existing delayed Blob URL cleanup is retained for reliable browser downloads.
